# RULES — Olive & Vine 한글 카피 다듬기 규칙 (최신본)

> 작업 본질: 영→한 신규 번역이 아니라 **기존 한국어 문장의 품질 개선**. 코드 구조는 절대 보존, 한국어 string 값만 교체.

## 핵심 원칙
1. **정확성** — 원래 의미·정보를 왜곡·누락하지 않는다. 직역투는 그대로 두지 않는다.
2. **자연스러움** — 한국 B2B 프리미엄 사이트답게 읽히도록. 단, **이미 자연스러운 문장은 무리해서 바꾸지 않는다(과도한 손질 금지).**
3. **일관성** — 용어·문체·톤을 사이트 전체에서 통일.

> **적용 범위 = 사이트 전체(본문 페이지 + 인사이트 아티클 동일).** 인사이트 본문도 서비스 본문과 같은 문체·용어·톤을 따른다(별도 인사이트 스타일 없음). 본문 페이지의 길게 작성된 한국어 레지스터(병기·~합니다 문어체·우리 인칭·사이트 용어)를 인사이트에 그대로 적용한다. (2026-06-23 사용자 확정)

## UI 요소별 문체
| 유형 | 문체 |
|------|------|
| 헤딩/타이틀 | 핵심 명사 단독, 군더더기 없이 |
| 본문(단락) | 완성형 문어체 종결 (~합니다 / ~해 드립니다 / ~지향합니다) |
| 불렛 | **명사형 종결**, 공백 포함 25자 내외, 병렬 구조. 종결어미(~합니다) 금지. 나열은 가운뎃점(·)으로 |
| 버튼/CTA | 짧은 동사형·명사형 행동 유도 |
| 라벨/메타 | 간결한 명사구 |

## 톤 & 보이스
- 전문적·신뢰감 있는 세련된 문어체. 과장·구호 절제.
- 동행·신뢰 어조: 권위적 단정보다 함께한다는 결. `함께 고민합니다`, `곁에서`, `~이 먼저입니다`.
- 인칭(v7 개정 — **검수에서 v6 역전**):
  - **기본 인칭 = `우리`.** 2026-06 검수 라운드에서 services·values·about 서사/본문의 `저희`가 광범위하게 `우리`로 교체됨(예: corporate "저희는 설립…" → "우리는…", values "저희의 성장" → "우리도 함께 성장"). 브랜드 보이스가 겸양보다 대등한 파트너 톤을 지향.
  - **겸양 `저희`는 직접 고객 응대 문구에만 한정** — 문의/CTA/문의 폼 안내 등(예: "문의 남기기" 주변 안내문). 서사·가치·서비스 설명 본문에는 쓰지 않는다.
  - you/your → 고객/여러분 최소 사용, 맥락 흡수. 남발 금지.
  - ⚠️ v6의 "메뉴 라벨 `우리의 X` 고정"은 폐기 — 아래 '영문 유지 면' 참조(섹션 eyebrow는 영문 `Our X`로 전환됨).
- 고유명사: 브랜드명 `Olive & Vine`은 영문 표기가 원칙. 단, 2026-06 검수에서 일부 서사 본문(leadership·consulting·tax intro)에 음차 `올리브 앤 바인`이 도입됨 → 음차 허용 범위는 REVIEW_QUEUE 미결(혼용 상태). 인명은 한국어 우선 표기(아래 '인명 표기 규칙').
- 호흡: 한 문장 한 호흡. 긴 문단은 분할.

## 라벨 위계 규칙 (리더십) — v7 갱신
- **섹션 eyebrow 라벨 → 영문 `Our X`** (검수에서 v5 '주요 리더십' 역전): `Our Founders`, `Our Leadership` 등. 아래 '영문 유지 면' 규칙에 통합.
- **개인·카드 단위 역할 라벨 → 영문 `Co-Founder`** (검수에서 '공동창업자' → `Co-Founder`로 교체됨).
- **인물 bio 본문 표기 → `이름 + 회계사` 존칭** 허용(예: "박지현회계사는…", "김미영 회계사는…").
- 원칙: 섹션/카드 라벨은 영문 미니멀, 본문은 한국어 존칭 — 위계와 톤을 분리한다.

## 번역투(calque) 금지
| 영문 | 금지 | 권장 |
|------|------|------|
| deserve | "받을 자격이 있다" | 펌의 신념·제공 가치로 재구성 |
| more than X | "X 이상의 것" | "X에서 끝나지 않는다 / X를 넘어" |
| their/them | "그들의/그들을" 남발 | 생략·맥락 흡수 |
| sounding board | "울림판" | "함께 고민하는 상대" |
| advocate | "옹호자" | "든든한 지원군" |
| 수동태·명사구 나열 | "~에 의하여" | 능동·서술형 재배치 |
| insight(s) | "통찰" | **"인사이트"**(검수 선호) |

## 이중 표기(병기) 규칙 — v7 신설
검수 라운드에서 일관되게 나타난 핵심 패턴. **한국어 단독이 아니라 `한국어 + 영문`(또는 영문 약어 병기)**으로 둔다.
- **브랜드 가치어·핵심 개념 라벨 → `한국어 + 영문` 병기:**
  `정직성 Integrity` · `탁월성 Excellence` · `파트너십 Partnership` · `공감 Compassion` · `성장 Growth` · `명확성 Clarity` · `접근 방식 Methodology` · `철학 Philosophy`
  (값 이름·섹션 개념 라벨에 적용. 영문은 괄호 없이 공백으로 병기.)
- **전문 약어·법령·기관 → 첫 등장 시 `한국어(영문 약어)` 병기**, 이후 약어:
  `세무국(IRD)` · `법인세 신고서(PTR)` · `국제회계기준("IFRS")` · `중소기업회계기준("SME-FRS")` · `홍콩 회사조례(Companies Ordinance)` · `아포스티유(Apostille)` · `공증인(Notary Public)` · 고용주 신고서 `IR56A 및 IR56B`.
- 목적: B2B 프리미엄 + 한·홍 양쪽 독자 모두에게 정확. 한국어만 두어 의미가 흐려지지 않게.

## 영문 유지 면 — v7 신설
다음 위치의 라벨은 **한국어로 옮기지 않고 영문 유지**(검수 확정):
- **섹션 eyebrow(브랜드 헤더):** `Our Story` · `Our Values` · `Our Mission` · `Our Promise` · `Our Founders` · `Our Leadership` · `What we believe` · `Who we serve`.
- **통계 스트립 라벨 전부 영문:** `Accounts Managed` · `Client Retention` · `Returns Filed` · `Tax Savings` · `Companies Incorporated` 등 (labelKo도 영문).
- **자격증·직함 약어:** `HKICPA (Practising)` · `CIA` · `Co-Founder` (음차/번역 금지 — v5 '실무'·'공동창업자' 역전).
- **영어 고객 세그먼트 명:** `SMEs (Small and Medium Enterprises)` · `Growing Regional Businesses` 등(본문 설명은 한국어).
- 판단 기준: **반복 노출되는 짧은 구조 라벨**은 영문 미니멀, **읽고 이해해야 하는 본문**은 한국어.

## CTA·내비게이션 표준어 — v7 신설
동일 기능 버튼은 사이트 전체에서 같은 문구로 통일(검수 확정):
| 기능 | 표준 문구 |
|------|-----------|
| 문의 유도(주 CTA) | **문의하기** (← '대화 시작하기') |
| 문의 폼 안내 | **문의 남기기** (← '편하게 연락 주세요') |
| 연관 서비스 링크 | **연계된 다른 서비스** (← '함께 살펴보기' / '관련 서비스') |
| 상세 보기 | **자세히 보기** (← '프로필 자세히 보기') |
| 뒤로 가기 | **이전 페이지** (← 'X(으)로 돌아가기') |
| 더 보기(일반) | **더 알아보기** (← '전체 X 보기' / '모든 서비스') |
| 인사이트 더 보기 | **더 보기** (← '모든 인사이트') |

## 인명 표기 규칙 — v7 신설
- **한국어 이름 우선 + 영문 이름 병기(괄호 없이):** `박지현 Rebecca`. (← `박지현 (Rebecca)`, `Rebecca, PARK Ji Hyun`)
- **한국어 단독도 가능:** `김미영` (영문 불필요 시 생략).
- 자격증·직함 약어는 영문(위 '영문 유지 면').
- bio 본문에서는 `이름 + 회계사` 존칭 사용(`박지현회계사`, `김미영 회계사`).

## 용어 일관성: 사이트 버전이 마스터 — v7 (2026-06-23 확정)
같은 영어 용어는 **사이트(서비스 페이지) 버전으로 전 자산 통일**. 인사이트 아티클을 다듬을 때도 **무조건 사이트 버전을 따른다**(사용자 확정).
| 영문 | 사이트 통일어(마스터) | 비고 |
|------|---------------------|------|
| Profits Tax | **법인세**(Profits Tax) | 인사이트 '이익세'→'법인세' 일괄 |
| Salaries Tax | **소득세** | 인사이트 '급여세'→'소득세' 일괄 |
| bookkeeping | **기장** | 인사이트 '부기'→'기장' |
| compliance | **컴플라이언스** | |
| insight(s) | **인사이트** | '통찰' 지양 |
- 원칙: 서비스 페이지에서 검수로 확정된 한국어가 사이트 표준. 인사이트는 거기에 맞춘다.
- ⚠️ 단, 인사이트 본문에서 세목을 처음 소개할 때 정밀성이 필요하면 '법인세(Profits Tax)' 병기 허용(이름 자체는 법인세).

## 사실 정확성 검수 — v7 신설
번역 품질과 별개로, **날짜·마감·법정 수치는 사실 검증** 대상. 2026-06 Tax 캘린더 검수에서 마감월 오류 다수 교정됨(예: '5월'→'4월 말', 예정세 일정 정정). 출처는 IRD/gov.hk 기준으로 확인하고 LOG에 남긴다.
